---
title: Razorpay webhooks
description: Add a Razorpay webhook signing secret that cb makes, then let cb create the webhook in Razorpay or paste it yourself.
---

For Razorpay, cb makes the webhook signing secret for you. With **Connect Razorpay**, cb also creates the webhook in
your Razorpay account using the Razorpay key saved in the same environment, so there is nothing to copy. If you would
rather add the webhook in Razorpay yourself, cb shows the URL and the secret once, to paste there.

## Before you start

- The environment has a **Razorpay** variable with your **Key secret** and **Key ID**. See
  [Razorpay](/docs/connectors/payments/razorpay). Connect needs the Key ID.
- The backend has a public address in `PUBLIC_URL`. See [Give cb a public address](/docs/guides/webhooks/public-url).
- You are an owner or admin of the organization.

## Connect Razorpay

<Steps>
<Step>
### Add the webhook variable

Open your project, pick the environment, and go to the **Variables** tab. Click **Add variable**, then fill in the
form:

<Fields title="Required">
  <Field name="Key" type="text" required>
    The name your code reads, for example `RAZORPAY_WEBHOOK_SECRET`.
  </Field>
  <Field name="What is this?" type="select" required>
    Choose **Webhook signing secret**.
  </Field>
  <Field name="Provider" type="select" required>
    Choose **Razorpay**. The form then has no secret field: cb makes the signing secret.
  </Field>
  <Field name="Path in your app" type="text" required>
    The route that handles webhooks in your app, for example `/api/webhooks/razorpay`. It must start with a single `/`
    (not `//`) and contain no spaces.
  </Field>
</Fields>

Click **Save & test**. The dialog changes to **Connect Razorpay**.
</Step>
<Step>
### Click Connect Razorpay

cb creates one webhook in your Razorpay account at the variable's cb URL through Razorpay's webhooks API (a normal
merchant key is enough), with the secret cb made and keeps, subscribed to
these events: `payment.authorized`, `payment.captured`, `payment.failed`, `order.paid`, `refund.created`,
`refund.processed` and `refund.failed`.

The panel now reads "Connected to Razorpay — events go to cb, then only to the developer who caused them." and lists
the events, with an **Open in Razorpay** link (`https://dashboard.razorpay.com/app/webhooks`) to add or remove events
in the Razorpay Dashboard.

This setup is also in the variable's Edit dialog and on the **Webhooks** tab of the environment.
</Step>
<Step>
### Make a test payment

Start your app with [`cb run`](/docs/guides/develop/cb-run) and create an order or payment from it. Each event shows
up in the terminal:

```bash
cb: webhook razorpay payment.captured → 200 (11 ms)
```
</Step>
</Steps>

## Reconnect after the address changes

If `PUBLIC_URL` changes, the panel shows "Razorpay still sends to an old address of this cb server. Reconnect to
point it here." Click **Reconnect**: cb updates the same webhook in Razorpay and keeps its secret. A webhook deleted
in Razorpay is created again.

## Remove the webhook

Removing the webhook variable switches its webhook off in Razorpay (Razorpay has no way to delete it through its
API). The confirmation dialog says so before anything is removed. You can delete the webhook in the Razorpay
Dashboard if you like.

## Set it up yourself

Use this when the environment has no Razorpay key, or you prefer to add the webhook in Razorpay by hand. In the
**Connect Razorpay** dialog, open **Set it up yourself**. Without a Razorpay key in the environment, the URL and the
secret are shown directly.

<Frame src="/docs/images/guides/razorpay-secret.png" alt="Connect Razorpay: the webhook URL and the signing secret cb made (blurred here) to paste into Razorpay" caption="Connect Razorpay: the webhook URL and the signing secret cb made (blurred here) to paste into Razorpay" />

<Steps>
<Step>
### Copy the URL and the signing secret

The panel shows **Webhook URL · paste into Razorpay** and **Signing secret · paste into Razorpay**, each with a copy
button.

<Callout type="warning" title="The secret is shown only once">
  Copy the signing secret before you close the dialog. cb never shows it again. If you lose it, click **New secret**
  on the Webhooks tab to make another one.
</Callout>
</Step>
<Step>
### Add the webhook in Razorpay

In the Razorpay Dashboard, open **Account & Settings → Webhooks → Add new webhook**. Paste the URL and the secret,
pick your events and save.
</Step>
</Steps>

### Make a new secret

On the **Webhooks** tab, a webhook whose secret cb made shows **New secret** (under **Set it up yourself** when the
environment has a Razorpay key). It makes a new signing secret and shows
it once. The old secret stops working at once, so paste the new one into Razorpay right away.

**New secret** is offered only for a secret cb made. A secret someone entered by hand is never offered for
replacement. It is also not offered for a webhook that cb connected (use **Reconnect** instead), and the API refuses it
with "cb manages this secret with Razorpay. Use Reconnect instead of a new secret."

## Common errors

| Message | Fix |
|---|---|
| Add your Razorpay key (type Razorpay) in this environment first; cb uses it to create the webhook in Razorpay. | Add a **Razorpay** variable in the same environment, then connect again. |
| The Razorpay key in this environment has no Key ID; edit it and add one. | Edit the Razorpay variable and fill in **Key ID**. |
| This cb server has no public address (PUBLIC_URL), so Razorpay could not reach it. | Set `PUBLIC_URL` and restart the backend. See [Give cb a public address](/docs/guides/webhooks/public-url). |
| Razorpay did not create the webhook: … You can add it in the Razorpay Dashboard with the URL and secret instead. | Check the Razorpay key, or use **Set it up yourself**. |
